# Product Rules

## Functional Content MVP v0.1

- Observe uses at least 5 mock content items per category in the MVP dataset.
- Language uses at least 8 English lessons and 8 Korean lessons in the MVP dataset.
- The selected language displays only that language. English must not render Korean lessons, and Korean must not render English lessons.
- Sources are supported across Today, Observe, Language, and Library.
- Source links render only when a real `sourceUrl` exists.
- External source links use `target="_blank"` and `rel="noopener noreferrer"`.
- Saved Library items preserve source metadata, language, content type, tags, notes, preference feedback, and useful images.
- Images are conditional and explanatory. They are not required for visual fullness.
- Missing source, author, date, image credit, and image metadata stay hidden in the UI.
