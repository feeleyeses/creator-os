# Codex Start Prompt

You are the first developer of Creator OS.

Read every file in this Developer Pack before editing code.

Your task is to build the first usable MVP, not a complete product.

## Objective

Create a responsive web application with four usable pages:

1. Today
2. Observe
3. Language
4. Library

## Priorities

1. Clear reading experience
2. Useful mock content
3. Responsive desktop and mobile layout
4. Working navigation and basic interactions
5. Consistent quiet editorial visual language

## Required behavior

- Use realistic mock content relevant to self-media, design, K-Hiphop, AI, e-commerce, English and Korean.
- Today must immediately feel alive.
- Include Today's Focus and Fresh Finds prominently.
- Keep AI notes to one or two sentences by default.
- Allow saving content to Library.
- Add lightweight preference controls such as `Interested`, `Not interested`, and `Not my taste`.
- Use local state/localStorage first.

## Do not build yet

- Authentication
- Production database
- External AI integration
- Complex recommendation algorithms
- Social features
- Gamification
- Full Create or Growth systems

## Working method

1. Inspect the existing repository.
2. Preserve useful existing work.
3. Create a small implementation plan.
4. Implement the complete walking skeleton.
5. Run lint/build/tests.
6. Summarize changed files, current limitations and the next highest-value improvement.

When a detail is unspecified, choose the simplest implementation that follows the product principles. Do not stop for minor questions.
