# Product Rules

## Global

- No infinite scroll.
- No streak pressure, rankings or celebratory gamification.
- No default notification red dots.
- No large AI chat panel on core reading pages.
- Every page must have a clear primary action or focus.
- Mobile must be designed for quick, one-handed reading.
- Default state is alive: useful content is immediately visible.

## Today

- First screen contains at most four clear blocks.
- Recommended structure:
  - Today's Focus
  - Fresh Finds / Worth Exploring
  - Editor's Note
  - Continue Learning
- Today's Focus and Fresh Finds should sit side by side on desktop.
- The opening may use: `今天，先看这件事。`
- Editor's Note defaults to one or two sentences.

## Observe

- Prioritize self-media, design/aesthetic references and K-Hiphop.
- Also include AI, e-commerce and light culture content.
- Each item should support: What / Why / Connection.
- Avoid presenting a raw firehose of news.

## Language

- English and Korean are first-class sections.
- Include vocabulary, grammar, internet slang, idioms and useful sentences.
- Support exam goals and real cultural understanding together.
- Allow one primary lesson plus smaller secondary exposure.

## Library

- Library is not only a bookmark folder.
- Saved items must support tags, category, notes and related content.
- The UI may initially use local mock data or local storage.

## AI

- Default AI presence should be visually secondary.
- AI notes should usually occupy no more than 10–15% of a page.
- One insight at a time.
- Expand only after explicit user interest.
- Explain recommendation reasons.
- If silence is better, remain silent.
