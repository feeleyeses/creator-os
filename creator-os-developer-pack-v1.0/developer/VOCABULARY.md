# Vocabulary

Use these product terms consistently.

| Use | Avoid |
|---|---|
| Today | Home / Dashboard / 首页 |
| Today's Focus | 今日推荐 / 热点 |
| Fresh Finds | 猜你喜欢 |
| Editor's Note | AI总结 / AI推荐 |
| Observe | 新闻流 / 资讯大厅 |
| Language | 学习中心 |
| Library | 收藏夹 |
| Create | 创作中心 |
| Growth | 个人中心 / 我的 |
| Continue Learning | 最近学习 |
| Journey | 打卡记录 |

Product voice should be short, calm, editorial and clear.
