# Project Context

## Product definition

Creator OS is **a place to understand the world**.

It helps one user explore information, language, culture, design, music, AI and business without being overwhelmed by them.

The product follows this loop:

`Curiosity → Understand → Connect → Express → Grow → Curiosity`

## Founder context

The first user:

- follows K-Hiphop deeply, including artists, producers, labels, lyrics and culture;
- studies English and Korean;
- values design, especially packaging, editorial layout and visual systems;
- follows AI, self-media and e-commerce developments;
- prefers one main learning focus with several lighter secondary inputs;
- prefers context and explanation over raw news;
- dislikes noisy, addictive and overly complicated products.

## Real usage

Expected daily use:

- morning commute: Today and Observe;
- lunch break: Language and quick reading;
- evening commute: Library and continued reading.

The app must open with useful content already visible. Do not use an empty or loading-first experience.

## MVP goal

Build a version the founder can use immediately and evaluate in real life.

The MVP is not expected to be complete. It must be coherent, readable and functional.
