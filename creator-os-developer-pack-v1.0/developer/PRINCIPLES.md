# Principles

1. **Understand the world.** Growth is the result of understanding.
2. **Growth before engagement.** Never optimize for screen time alone.
3. **Respect attention.** Reduce noise, urgency and unnecessary interruption.
4. **Understand before consume.** Explain why something matters.
5. **Language is a window.** Language learning connects to culture and real use.
6. **AI is editorial.** AI explains, connects and recommends; it does not dominate.
7. **Observe, do not chase.** Surface trends without forcing the user to follow them.
8. **Reading first.** Interface and motion must serve comprehension.
9. **Guide, never push.** Preserve user autonomy.
10. **Build first, refine later.** Once worldview and core principles are stable, implement usable functions before further theoretical expansion.
